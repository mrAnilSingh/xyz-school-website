# XYZ School Website Demo

A simple, responsive informational school website created as a client demo.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- No database
- No login / ERP
- No build process

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `xyz-school-demo`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide a URL similar to:
   `https://YOUR-USERNAME.github.io/xyz-school-demo/`

## Before showing the client
Replace:
- XYZ School name
- Logo
- Phone number
- Email
- Address
- Google Maps URL
- WhatsApp number
- School photos
- Principal's message
- Admission details
- Academic information
- Facilities
- Gallery images

The current demo uses remote Unsplash images only as placeholders.

## Connecting the final `.in` domain
After the school purchases its domain and hosting, the final deployment can be moved to the selected hosting provider and the domain DNS can be pointed to it.
